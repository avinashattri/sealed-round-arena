P3.T2 verify tests (1.5 h)
- referee/verify/tamper.py (each takes a list of JSON lines, returns a changed copy): flip (change event of entry 3), delete (drop entry 2), reorder (swap 2 and 3), truncate (drop last 3), replay (duplicate entry 3). ALL = {flip, delete, reorder, truncate, replay}. tests: build a clean 12-entry log + signed checkpoint with a throwaway SigningKey; clean = PASS; each tamper fails with the words "content changed", "missing seq", "out of order", "truncated", "duplicate seq"; the 5 reasons are 5 different strings.
- make verify: `.venv/bin/python -m referee.verify.verify evidence/audit_export.jsonl --pubkey evidence/audit_pubkey.hex --checkpoint $(ls -t evidence/anchors/*.json | head -1)`. make tamper-demo: scripts/tamper_demo.py applies each tamper to an in-memory copy of the real export and prints each failure reason (never writes the real log).
- Done: `.venv/bin/pytest referee/verify -q` green. Err: clean log fails "entry_hash mismatch" -> test fields and verifier fields must both be "every field except entry_hash and sig", prev_hash included.

P3.T3 Commit-reveal, sealed boxes, broker hooks (2 h)
- contracts/crypto/commit.py: make_commitment(items) -> (nonce_hex, commitment_hex); check_commitment. seal.py: new_round_keys(), seal(pub_hex, data), unseal(priv_hex, blob) (PyNaCl SealedBox). Broker: POST /admin/load_round {round_id, pub, temperature, seed_base}; POST /admin/audit (controller writes events through the broker so the broker stays the only audit writer); POST /admin/submit (controller's benign stream, principal controller). flow.audit(event, cid, content=None, actor="broker"): content_hash = sha256(content); content sealed with the round public key to /sealed/<round>/<cid>.<event>.<n>.bin; sealed_ref set; failure raises. call_model: temperature from the round, seed = seed_base + n, cache_prompt false unless MODEL_CACHE=on (unit test asserts it).
- Done: `.venv/bin/pytest contracts referee/broker -q` green with: commitment OK on same items; fails when one payload changes; seal/unseal round trip; wrong private key raises; one flipped ciphertext byte raises. Err: CryptoError at reveal -> broker restarted and lost the public key; re-run load_round.

P3.T4a Controller phases 0-4 (2 h) and T4b reveal + results (2 h)
- referee/controller/{__main__,phases,util}.py. CLI: `python -m referee.controller run --campaign c-001 --round r-001 --attacks loop/data/attacks/F1.json --defense 1 --size mini|demo|full [--tamper-attack ch-0003] [--stub-model] [--stand-in-red] [--fresh]`. Sizes: mini = 3 attacks, 3 benign, 1 repeat; demo = items x 2 repeats + 40 benign; full = items x 6 repeats + 120 benign. util: dc(*args) (compose cmd for hardened), admin(route,obj) via `docker compose exec -T broker python -m broker.admin post`, emit(), image_id(name) via `docker image inspect --format '{{.Id}}'`.
- 0 PROVISION: --fresh -> `bash infra/scripts/up.sh hardened`, else `up -d --force-recreate broker blue red oracle --wait` with BLUE_IMAGE=sra/blue:v<N>; pin_check(); new round keys; load_round; emit campaign_created. 1 COMMIT: commitment over the attack set; emit commit (red: content_hash; blue: defense_digest=image id; controller: model_digest + policy_version); move COMMITTED; write secrets red_attacks.json (+ tamper: payload + " " for --tamper-attack) and red_meta.json. 2 SEAL: assert Blue image id unchanged; move SEALED; emit seal. 3 EXECUTE: move EXECUTING; Red client (`docker compose exec -T red python -m red.client`) and the benign stream run concurrently; --stand-in-red sends attacks via /admin/submit as controller and is labelled STAND-IN. 4 CLOSE: move CLOSED; emit close BEFORE the checkpoint; checkpoint -> evidence/anchors/<round>.json; copy /sealed/<round> to evidence/sealed/; export log to evidence/audit_export.jsonl; pubkey (from the signing seed) to evidence/audit_pubkey.hex; assert images unchanged.
- 5 REVEAL: unseal every file with the round private key to evidence/revealed/<round>/; check each file's sha256 equals its logged content_hash (else "HASH MISMATCH at seq N"); recompute the commitment from the request_received payloads actually sent; mismatch -> exit with `COMMITMENT MISMATCH: ['ch-0003']`; move REVEALED; emit reveal. 6 RESULTS: write evidence/results/<round>/results.json (per challenge: label, gateway, input, output, oracle, path; labels come only from here).
- make reveal-demo: mini size, --stub-model (profile stubmodel, MODEL_URL=http://stubmodel:8080), --tamper-attack ch-0003; `grep -q "COMMITMENT MISMATCH"` then print "OK: the altered attack was caught".
- Done: one round with stubs prints one status line per phase; `make verify` PASS on the export; `--tamper-attack ch-0001` ends "COMMITMENT MISMATCH: ['ch-0001']". Err: `docker compose cp` finds nothing -> load_round used a different round id.
